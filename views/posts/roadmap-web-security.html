Chào mọi người, dưới đây là tài liệu tham khảo về định hướng và lộ trình học tập mảng Web Security dành cho các bạn có niềm đam mê với Website. Lộ trình được đúc kết từ kinh nghiệm thực tế, chia thành các giai đoạn cụ thể để các bạn dễ theo dõi.

1.2. Các concept cơ bản trong web

  • Cấu trúc của URI, URL
  • HTTP request, response có cấu trúc như thế nào, có các trường thông tin nào, các trường thông tin phục vụ mục đích gì.
    • Phần này chỉ cần học sơ qua để phân biệt được GET, POST, PUT, DELETE, OPTIONS khác gì nhau.
    • Các trường phổ biến như: Host, Content-Type, Cookie,... có ý nghĩa gì. Phần này newbie thì học sơ qua, đến khi giải từng bài CTF sẽ hiểu hơn về các trường thông tin khác (sẽ giới thiệu về CTF sau)
  • Cách xem source code của web, Inspector. DevTools của trình duyệt
  • Cookie, session, localStorage: hiểu cách web tracking người dùng như thế nào
  • DNS, URL structure, encoding (URL encode, base64, HTML entity)

2. Giai đoạn 2: Biết cách lập trình 1 ứng dụng web và hiểu các concept nâng cao hơn (1-2 tháng)

2.1. Lập trình 1 ứng dụng web sử dụng MVC

Ngôn ngữ lập trình có thể tuỳ chọn. Có thể chọn các ngôn ngữ cơ bản, dễ cho người mới có thể chọn NodeJS, PHP, Python. Hoặc nâng cao hơn như Java, C#.

Mục tiêu là viết 1 ứng dụng web cơ bản sử dụng mô hình, có các chức năng như:

  • Đăng ký/đăng nhập
  • Upload file
  • Một trang hiển thị dữ liệu từ database

Muốn viết 1 web có chức năng này thì các bạn đã phải động đến các kiến thức như Cookie, Session (mục 1.2) và học cách viết SQL (lấy và hiển thị dữ liệu từ database)

2.2. Lập trình 1 ứng dụng web sử dụng mô hình front-end và back-end tách biệt

  • Sử dụng front-end tuỳ chọn: ReactJS, AngularJS, VueJS
  • Back-end có thể sử dụng:
    • Java (SpringBoot) -> giai đoạn này nên tập sử dụng các ngôn ngữ như Java, nâng độ khó và làm nền tảng để học các dạng lỗ hổng nâng cao hơn. Riêng Java sẽ có 1 note riêng
    • NodeJS (ExpressJS, NestJS)
    • ... có rất nhiều ngôn ngữ khác, tuy nhiên do giai đoạn trước đã học các ngôn ngữ script đơn giản như JS, PHP, Python rồi thì giai đoạn này học ngôn ngữ có thông dịch để hiểu hơn về các cơ chế như run-time, build-time,....

3. Giai đoạn 3: Web Security cơ bản

Lưu ý: Khi học tới giai đoạn 2 đã có thể học web security song song với việc học lập trình, tìm hiểu thêm về các công cụ được sử dụng trong việc khai thác lỗ hổng web.

Việc học lập trình web giúp ta có nền tảng để đi xa hơn, tuy nhiên để trở thành "hacker" thì ta cần rèn luyện mindset hacker.

Để rèn luyện mindset như hacker thì cần bắt đầu học các lỗ hổng web cơ bản như:

  • SQL injection: học SQL để code web rồi thì học luôn SQL injection
  • XSS
  • IDOR / Broken Access Control

3.1. Các nền tảng để học web security

Các bài nền tảng học web security để luyện tập có thể kể đến như:

  • Root-me: https://www.root-me.org/
  • Portswigger: https://portswigger.net/

a. Root-me (mục Web Server):

Các dạng bài siêu dễ:

  • HTML - Source code
  • HTTP - IP restriction bypass
  • HTTP - User-agent
  • Weak password
  • Backup file
  • HTTP - Directory indexing
  • HTTP - Headers
  • HTTP - POST
  • HTTP - Improper redirect
  • HTTP - Verb tampering
  • Install files
  • HTTP - Cookies
  • HTTP - Open redirect

b. Portswigger

Các lab có mức độ kiến thức cơ bản:

  • SQL injection
  • Path traversal
  • Command injecton
  • Information disclosure
  • Business logic vulnerabilities
  • File upload vulnerabilities
  • Authentication
  • Access control
  • Cross-site scripting (XSS)
  • Cross-site request forgery (CSRF)
  • Cross-origin resource sharing (CORS)
  • Clickjacking
  • DOM-based vulnerabilities
  • WebSockets
  • Server-side template injection
  • HTTP Host header attacks

Thật ra trong đống này cũng ko phải cái gì cũng cơ bản đâu :)) Nhưng tinh thần là vừa làm vừa tìm hiểu thêm.

4. Web Security nâng cao

Các dạng lỗi ở phần này khá phức tạp, cần tìm hiểu thêm nhiều cơ chế liên quan để làm.

a. Portswigger

  • Race conditions: Cần tìm hiểu thêm về các khái niệm trong hệ điều hành như thread, process
  • XXE injection: Cần tìm hiểu thêm về XML, XML là 1 công nghệ khá cũ. Tuy khá cũ nhưng hiện nay các framework trong Java vẫn thường sử dụng dạng công nghệ này.
  • NoSQL injection: Tìm hiểu thêm về các dạng database NoSQL như MongoDB
  • JWT attacks
  • API testing: Học lập trình mô hình web ở mục 2.2 để có nền tảng hơn về phần này
  • Web cache deception, Web cache posoning: Cần tìm hiểu thêm về cơ chế cache. Đọc thêm về Redis, Memcached
  • GraphQL API vulnerabilities: Tìm hiểu thêm công nghệ GraphQL, một công nghệ khá hay trong việc xây dựng API
  • OAuth authentication: Tìm hiểu thêm về SSO, OAuth, OIDC. Thậm chí là cả SAML
  • HTTP request smuggling: Đây là 1 dạng lỗi mình đánh giá là khá hay, tác giả của lỗi này là James Kettle (albinowax). Cá nhân mình thấy một người nghĩ ra 1 dạng attack vector mới hoàn toàn như này xứng đáng được xếp vào dàn tinh hoa của nhân loại.
  • Prototype pollution & Insecure deserialization: 2 dạng lỗi phức tạp nhất khi học về web security. Đây là các dạng lỗi đi kèm theo "tính chất" của từng ngôn ngữ lập trình. Riêng về lỗi này sẽ dành ra 1 phần riêng.
  • Web LLM attacks: Một dạng lỗi "suýt mới" khi dần có các mô hình LLM được ra mắt

b. Root-me (Web-Server)

Làm nốt các dạng bài còn lại. Có thể nói khi học đến tầm này rồi thì các bạn đã có khả năng tự research và giải hết các dạng bài.
